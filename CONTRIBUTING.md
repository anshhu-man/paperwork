# Contributing to PaperWork

Thank you for helping make paperwork easier to understand.

Before opening a pull request:

1. Describe the user problem and the document type affected.
2. Preserve the distinction between source facts, PaperWork inferences,
   suggested actions, conflicts, and unconfirmed information.
3. Add or update tests for citation coverage and unsupported claims when the
   analysis layer is involved.
4. Never add telemetry, retention, or external data transmission without a
   visible user disclosure and documented threat-model update.
5. Run `npm run build` locally.

Accessibility, translation, privacy, evaluation, and document-domain
contributions are especially welcome.
