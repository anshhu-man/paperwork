# Security policy

PaperWork is designed for documents that may contain sensitive information.
Please do not disclose a vulnerability through a public issue when it could
expose user data.

Until a dedicated private reporting address is published, create a minimal
public issue stating that you have a security report without including exploit
details or confidential material. A maintainer will arrange a private channel.

The current prototype does not upload, parse, retain, or send selected file
contents to an AI provider. Any future processing capability must update the
threat model and user-facing data-flow receipt before release.
